# Резервные копии

## Для кого и зачем
Чтобы сохранять историю вне браузера.

## Что должно быть
Экспорт JSON со всеми расходами и бюджетами. Проверка файла и предварительный просмотр количества записей. Замена всех данных только отдельной кнопкой, отмена без изменений. Атомарное сохранение.

## Примеры
Скачать копию, изменить запись, восстановить файл — прежние суммы вернутся.

## Ограничения
Локальные HTML, CSS и JavaScript без библиотек и сети. Старые данные совместимы. Поля и кнопки от 44 px, ширина 375 px.

## Готово, когда
Проверены восстановление, неверный формат, отмена и отказ записи. Файлы не отправляются в сеть.
