# Синхронизация вкладок

## Для кого и зачем
Чтобы вкладка замечала изменения другой вкладки и не сохраняла устаревший список.

## Что должно быть
Перечитывать данные по событию storage и при возврате фокуса. Перед записью сравнивать состояние хранилища с прочитанным; при изменении остановить действие и обновить данные. Незавершенное редактирование и отмена удаления сбрасываются с сообщением. Поврежденные данные не затираются.

## Примеры
Добавить трату в первой вкладке — вторая обновляет итог. Попытка сохранить устаревшее состояние отклоняется.

## Ограничения
Локальные HTML, CSS и JavaScript без библиотек и сети. Старые данные совместимы. Поля и кнопки от 44 px, ширина 375 px.

## Готово, когда
Проверены обновление, отказ устаревшей записи, поврежденные данные и восстановление. Ограничение: localStorage не гарантирует транзакции между одновременно пишущими вкладками.
