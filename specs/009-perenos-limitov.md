# Перенос лимитов

## Для кого и зачем
Чтобы не вводить одинаковый бюджет каждый месяц.

## Что должно быть
Кнопка «Взять из прошлого месяца» переносит лимиты только в категории без лимита выбранного месяца. Уже заданные суммы не заменяются. Нет исходных лимитов — понятное сообщение. Ошибка записи ничего не меняет.

## Примеры
В декабре еда 10 000, транспорт 5 000. В январе еда уже 12 000: перенос добавляет только транспорт 5 000.

## Ограничения
Локальные HTML, CSS и JavaScript без библиотек и сети. Старые данные совместимы. Поля и кнопки от 44 px, ширина 375 px.

## Готово, когда
Проверены переход года, частичный бюджет, повторный перенос, отсутствие исходных лимитов, F5 и отказ записи.
