# Поиск и история по дням

## Для кого и зачем
Чтобы быстро находить расходы в длинной истории.

## Что должно быть
Поиск по комментарию без учета регистра, фильтр категории, сброс. Отдельная сумма найденного; сводка месяца не меняется. Записи по дате расхода от новых к старым, внутри дня — последние добавленные сверху. Заголовки дней с датой, сегодня и вчера.

## Примеры
Комментарий «Такси домой» находится по «такси». При фильтре транспорта видно только транспорт и его найденную сумму.

## Ограничения
Локальные HTML, CSS и JavaScript без библиотек и сети. Старые данные совместимы. Поля и кнопки от 44 px, ширина 375 px.

## Готово, когда
Проверены поиск, фильтр, их сочетание, пустой результат, сброс, порядок и сохранность общего итога.
